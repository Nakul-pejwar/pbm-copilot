# 7-minute demo

1. Start on the Superset dashboard.
2. Point out 100K synthetic claims processed.
3. Explain anomaly rate and high-risk queue.
4. Drill into a provider with unusual volume.
5. Show a high-risk claim and its triggered rules.
6. Open `/docs` and call `GET /claims/{claim_id}`.
7. Call `POST /explain/{claim_id}`.
8. Explain that GenAI does not decide the anomaly; it explains evidence generated by the detection layer.
9. Close with production roadmap: real claims ingestion, RBAC, audit, model governance and human review.
